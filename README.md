# motomotos releases

**motomotos** turns the MacBook notch into a live Dynamic Island for AI coding: agent quota, terminal sessions, approvals, music — and a cat that knows how your day is going.

Website: https://motomotos.com · Support: support@motomotos.com

This repository only hosts installers and release notes. The app's source code is not public.

## Install

Open Terminal (⌘ Space, type `Terminal`, press Return), paste this line and press Return:

```bash
curl -fsSL https://raw.githubusercontent.com/ygalex0927-eng/motomotos-releases/main/install.sh | bash
```

The script downloads the latest `Motomotos.dmg` from this page, copies **Motomotos.app** into Applications, clears the "downloaded from the internet" flag and opens it. motomotos is not notarized by Apple yet, so a .dmg downloaded in a browser will be blocked by macOS; the Terminal line avoids that.

Requirements: Apple silicon Mac, macOS 13 or later. Best with a notched MacBook; with the lid closed on an external display, or on a Mac without a notch, the island sits at the top middle of the menu bar.
